# benatakan.com

Personal site of Atakan Savaş — built with Next.js.

**Live:** [benatakan.com](https://benatakan.com)

## Routes

- `/` — landing
- `/cv` — resume
- `/projects` — project archive, era by era
- `/san-ai` — San·ai, a shared software house in Dalyan · [@sanai.network](https://www.instagram.com/sanai.network/)
- `/mesai` — Mesai, an AI office for every project (closed beta)
- `/presentations` — decks on voice AI scenarios and AI cost models

## Stack

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · Three.js (react-three-fiber) · Lenis · ElevenLabs ConvAI

## Development

```bash
npm install
npm run dev
```

Deployed on Railway behind Cloudflare.
